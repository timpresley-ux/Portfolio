# Tecton Design System Integration

Working materials for the case study describing how Sperry translated the
Landmark-led Tecton Design System into a maintainable Angular and PrimeNG
implementation.

## Evidence boundaries

The Sperry PrimeNG Figma file was directly inspected. The original MUI and
Foundations files were not active in Figma during this review, so architectural
details about those files currently rely on the Head of UX's project account.

The initiative is ongoing. Do not imply that Tecton has completed cross-PSL
adoption, that the integration has formal enterprise governance, or that
quantitative impact has been measured.

## Confidentiality

Public visuals should reconstruct the architecture with generic tokens and
component names. Do not publish internal Figma screens, proprietary JSON,
company data, or internal disagreements.
