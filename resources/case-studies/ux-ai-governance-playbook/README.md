# UX / AI Governance Playbook

Source material and working content for the case study describing how Sperry
created a shared UX/UI knowledge layer for designers, product owners,
developers, and AI-assisted workflows.

## System generations

- **Pre-Tecton:** `D:\DEV\Design-System - Copy`
- **Tecton-era evolution:** `D:\DEV\Sperry-ux-toolkit-v1`

These are related generations, not the same design system. The earlier Sperry
DS implementation proved the AI-consumable shared-pool model. The later toolkit
translates that operating model onto Tecton components, tokens, and governance.
