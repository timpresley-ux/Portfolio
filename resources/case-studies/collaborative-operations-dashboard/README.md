# Collaborative Operations Dashboard

Source material for a portfolio case study about coordinating operational work
across planning, execution, and closeout.

## Asset status

The images in `reference-screens/` contain company branding, product terminology,
and realistic operational data. Treat them as private reference material. Do not
publish them in the portfolio without written approval and a deliberate
sanitization pass.

For public presentation, recreate only the UI patterns needed to support the
story, using fictional branding, entities, metrics, locations, and workflows.

## Strongest case-study angle

Frame the project as a decision-support and workflow-orchestration system, not a
dashboard redesign. The strongest narrative is how one information model helps
different roles move from portfolio-level exceptions to the next operational
decision while preserving context across the full service lifecycle.

Before publication, document the user's role, the business problem, the design
constraints, the author's specific decisions, and measurable outcomes. The
screens demonstrate breadth and consistency, but they do not establish impact
on their own.
