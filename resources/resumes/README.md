# Resume Sources

Editable source documents for the portfolio's role-targeted resume downloads.

## Variants

- `Tim-Presley-Resume-Head-of-UX.docx`
  - Primary version for Head of UX, UX Director, design leadership, and
    management-track opportunities
- `Tim-Presley-Resume-Head-of-UX.pdf`
  - Public download generated from the leadership source
- `Tim-Presley-Resume-Principal-UX-Designer.docx`
  - Primary version for Principal, Staff, design-systems, and senior individual
    contributor opportunities
- `Tim-Presley-Resume-Principal-UX-Designer.pdf`
  - Public download generated from the principal source

## Publishing

- Preserve these DOCX files as editable sources.
- Publish the reviewed PDF versions as public downloads.
- Use the Head of UX version as the default portfolio resume unless the site
  provides an explicit Leadership / Principal audience choice.
- Do not publish both under ambiguous labels such as "Resume 1" and "Resume 2."
- Reconcile portfolio claims and case-study evidence before producing the final
  PDFs.
